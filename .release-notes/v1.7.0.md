# v1.7.0

## Highlights

- Adds `use_electric_field=False` and `use_magnetic_field=False` to independently
  disable fields in backtrace, probability, octree, autorange, validation, and
  MPI/srun APIs. Both options default to `True`. Disabled fields are not loaded;
  electric-field opt-out includes accumulated charge, and magnetic-field opt-out
  includes the background field.
- Fixes the Boris rotation coefficient so oblique magnetic fields preserve
  particle speed and the velocity component parallel to the field.
- Corrects inverse Boris update ordering to match MPIEMSES3D's forward step,
  including sampling nonuniform fields at the recovered position and wrapping
  periodic field coordinates.
- Documents the field options and the conditions for reversible Boris steps
  in Japanese and English.

## Validation

- All 11 Fortran test programs pass with gfortran, including signed gyromotion,
  1,000-step magnetic invariants, nonuniform-field round trips, and periodic
  boundary crossings.
- All 31 Python unit tests pass, including independent field opt-outs and their
  propagation through the serial, MPI, and srun wrappers.
- Python/Fortran ABI and existing positional API arguments remain compatible.
- The rebuilt shared library passes real ctypes calls for speed conservation,
  uniform and nonuniform inverse steps, and field opt-outs.
- The source distribution passes package metadata and contents checks, builds
  its shared library on installation, and passes the wrapper import smoke test.
