# v1.8.1

## Highlights

- **Reliable rebuilds after interrupted builds.** fpm 0.12 does not recompile a target whose own
  source is unchanged unless a dependency is rebuilt in the same run. After a failed or
  interrupted run, unchanged dependents could keep stale `.mod` interfaces and derived-type
  layouts, which crashed later builds in unrelated code. `make build`, `make test`, `make batch`,
  `make batch-mpi` and `install.sh` (used by `pip install`) now go through
  `scripts/fpm-stale-guard.sh`, which detects an unfinished previous run and forces the affected
  targets to recompile. Direct `fpm` invocations are not covered.
- The dust-current and range-batch Python tests now use the installed shared library when the
  source tree has none, matching the CI source-distribution check.

No numerical, API or ABI changes relative to v1.8.0.

## Validation

- The source distribution contains `scripts/fpm-stale-guard.sh`, installs into a fresh virtual
  environment with gfortran, and the Python test suite passes against the installed library.
- Fortran tests pass with GNU + OpenMP.
