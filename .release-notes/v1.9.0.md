# v1.9.0

## Highlights

- **Sources follow what MPIEMSES3D injects.** Emission patches, raycast photoelectrons
  and the outer-boundary drift were checked against the EMSES implementation and
  corrected: patch tangents use `spe` on both axes, raycasts use the surface actually
  hit with its projected flux (the factor-2 approximation is gone), and EMSES inputs
  with `pe_ray_cast` now enable raycasts. The outer boundary keeps the field-frame
  thermal spread, which MPIEMSES3D v4.23.0 now also injects.
- **Geometry is the EMSES code.** `src/emses/collision/` holds byte-identical copies of
  the EMSES builders; vdist does not depend on EMSES at build time. `docs/emses_sync.md`
  and `scripts/check-emses-sync.sh` describe how to keep following it.
- **Unsupported EMSES settings are rejected** with `ValueError` instead of being ignored,
  and invalid geometry no longer stops the Python process.
- Autorange is about 18 % faster (1 thread) and 16 % faster (4 threads).

Probabilities change for inputs with emission patches, raycast photoelectrons, `vdx/vdy/vdz`
or annular disks. Inputs that now raise `ValueError` were not reproduced before.

### Added

- `rectangle-corners` (`rectangle_corners`) and `plane-with-circle-hole` internal
  boundaries, from the EMSES geometry builders.
- The C entry `validate_emses_input`, used by the Python wrapper to check an input
  before calling the native solver. Libraries without it keep the previous unchecked
  behaviour.
- `docs/emses_sync.md` and `scripts/check-emses-sync.sh`: how vdist follows EMSES and a
  check of the copied files and the EMSES commits to review.

### Changed

- The internal-boundary builders (`src/emses/collision/`) are byte-identical copies of
  MPIEMSES3D `src/physics/collision/`, so the geometry follows EMSES exactly.
- Inputs whose EMSES behaviour the static replay cannot reproduce raise `ValueError`
  before entering the native solver instead of being ignored: secondary electron
  emission, surface reflection, loss-cone/ring distributions, periodic raycasts,
  `omniemit`, two-component emission (`mainprop < 1`), patches without a positive
  `curf`/`curfs`, and patch-emitting species with `vdri ≠ 0`. Invalid geometry is
  reported the same way instead of stopping the Python process.
- Grid interpolation locates the cell once for all components of a nodal grid and
  only along the offset axes of a staggered one. Autorange is about 18 % (1 thread)
  and 16 % (4 threads) faster with identical results.

### Fixed

- Source distributions follow what MPIEMSES3D injects:
  - The outer-boundary drift includes `vdx`, `vdy`, `vdz`.
  - Emission patches use the mean `spa + abvdem` along the outward normal and `spe`
    on both tangents (`speth` is not used), as EMSES samples them. The current is
    `curfs` if positive, otherwise `curf` if positive. Photoelectron patches
    (`nflag_emit = 2` without raycast) are scaled by the incidence cosine from
    `thetaz`/`thetaxy` when `decrease_current_according_to_incident_angle` is set
    (default). `thetaz` and `thetaxy` are scalars as in EMSES.
  - Raycast photoelectrons use the normal of the surface actually hit, the EMSES
    tangent basis and the projected flux `|curf| max(n·sun, 0)`, normalised by the
    one-sided flux moment. The former sun-aligned normal and factor-2 approximation
    are removed. The sun direction comes from the EMSES camera, falling back to
    `vdthz(1)` and `vdthxy(1) - 180` like EMSES, and the occlusion test includes the
    EMSES non-emitting cover. The Python wrapper converts the EMSES key `pe_ray_cast`
    to `use_raycast`, so raycasts are enabled for EMSES inputs.
  - The one-sided flux moment uses `erfc`, which stays accurate when the drift points
    into the surface.
- Annular-disk end caps were built with the inner radius and height instead of the
  outer and inner radii.
- Grid interpolation on an axis with a single node no longer reads index -1; the axis
  is constant.
- Backtraces that cross a periodic face within one step now test the part of the
  step after the crossing against internal objects. An absorbing sheet just behind
  the seam was passed through and the external Maxwellian was returned instead of
  zero (#39). Collided positions on periodic axes are reported inside the domain.
- `read_namelist` restores the default of every namelist variable before reading,
  so an optional key such as `spa` set by one input no longer persists into the
  next input analysed in the same process (#40).
- Explicit emission patches (`nepl > 0`) emit only toward the side given by the
  sign of `nemd`; the rear side of a thin emitting panel no longer recovers the
  emission distribution (#41).
- The native source frame now matches the EMSES background field used by the
  Python wrapper: `thermal_basis` returns the EMSES frame matrix with
  `(sin(phiz)cos(phixy), sin(phiz)sin(phixy), cos(phiz))` as the parallel axis, the
  outer-boundary Maxwellian uses that frame for its covariance, and `spa`/`spe`/`speth`
  and `vdri`/`vdthz`/`vdthxy` follow the EMSES definitions (#42). EMSES 4.23.0 injects
  the same field-frame spread at the outer boundary.
  `speth` is now interpreted in degrees like every other namelist angle; inputs
  that relied on radians must be converted.
- `get_backtraces` no longer declares its per-particle work variables in a `block`
  inside the OpenMP loop. ifort 2023.2 at `-O2` and above (the camphor profile)
  mislaid the shared-variable pointers of the outlined region for a block holding a
  derived type with allocatable components, so the progress bar was read from
  garbage and every Python `get_backtrace` call crashed (#44). The variables are
  now procedure-scope `private` loop variables; `get_probabilities` follows the same
  layout. A direct Fortran test of the C entry point was added.
- Adaptive time steps stay finite at zero velocity and at electric-field turning
  points. The step solves `0.5*a*s**2 + |v|*s = dt` with the local acceleration
  instead of `dt/|v|`, in both the probability solver and the autorange tracer (#43).

## Validation

- KUDPC System B compute nodes, GNU Fortran 8.5: all 23 Fortran test programs (debug,
  bounds-checked), 60 Python tests including the batch executables.
- The copied geometry files are identical to MPIEMSES3D v4.23.0
  (`scripts/check-emses-sync.sh`).
- Autorange benchmark (16³ grid, 64 samples, 5 alternating pairs) against the previous main (`e722521`):
  -18.3 % (1 thread) and -16.3 % (4 threads), identical processed counts.
