# v1.5.0

## Highlights

- First PyPI-ready source distribution for `vdist-solver-fortran`.
- Adds optional particle-parallel MPI backend and `srun` launch wrappers.
- Aligns accumulated-charge electric-field handling with MPIEMSES3D by
  separating `phibk` / `phibksp*`-derived fields from relocated space-charge
  fields.
- Adds raycast photoelectron probability support.
- Removes the dust simulator code now maintained in a separate repository.

## Validation

- `fpm test`
- Python import smoke test
- `make package-check`
- sdist install smoke test with `INSTALL_PROFILE=generic`
