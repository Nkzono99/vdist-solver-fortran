# v1.7.1

## Highlights

- Fixes Maxwellian and raycast photoelectron sources in oblique magnetic fields.
  Evaluation uses the principal thermal frame, preserving isotropic rotation
  invariance and the full covariance of anisotropic distributions. Autorange
  support widths use Cartesian marginal standard deviations (#34).
- Corrects boundary collision times to use the actual signed step duration,
  including adaptive steps (#35).
- Fixes autorange deposits at periodic seams. Samples follow the unwrapped
  trajectory and are then mapped into the periodic domain, including multiple
  periodic axes and multiple crossings in one step (#36).
- Prevents crashes from uninitialized probability pointers during cleanup and
  from reading an absent optional surface-coverage argument.
- Updates Japanese and English documentation and adds real shared-library
  regression checks to CI.

## Validation

- All 12 Fortran test programs pass, including source normalization and
  covariance, signed fixed/adaptive collision times, periodic seams in
  nonuniform fields, and multiple periodic crossings.
- All 34 Python tests pass without skips. Three integration tests call the
  real shared library with small synthetic EMSES inputs.
- The rebuilt shared library passes the wrapper import smoke test.
- CI validates the source distribution, builds and installs its shared library,
  and runs the Python tests against that installed library.
- Existing public Python API arguments and the C ABI remain compatible.
