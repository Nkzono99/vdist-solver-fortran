# v1.8.0

## Highlights

- **Dust charging currents.** `get_dust_currents` evaluates the orbit-motion-limited
  flux moment `F(psi) = ∫ p(v) |v| sigma(v, psi) d^3v` on the adaptive velocity octree
  inside the Fortran core, for a whole `psi` grid in one pass. Multiply by `q n` to get
  the current density collected by a small dust grain. Results report a quadrature
  error bound, octree status and sample counts.
- **`vdsolverf-batch` executable.** A standalone serial or MPI program computes dust
  currents (and per-cell velocity ranges with `mode = "velocity_range"`) for many
  targets from a namelist batch directory. Rank 0 hands out chunks dynamically, each
  chunk is written atomically, and interrupted jobs resume. No Python is needed on
  compute nodes. Build it with `make batch` or `make batch-mpi`.
- **Field bundles.** `vdsolverf.io.field_bundle` writes the relocated fields and the
  trimmed namelist once, so octree, dust-current and autorange calls (and the batch
  executable) skip re-reading EMSES output.
- `VelocityOctreeResult.leaf_is_terminal` marks boxes that were not split.

## Behaviour changes

- **Emission-surface probabilities change scale.** The density of emission patches
  (`nflag_emit` with `curf`/`curfs`) was computed with swapped drift/thermal arguments
  and with the Gaussian sigma used as the erf width. It now matches the emitted current.
  For zero drift the probabilities grow by `sqrt(2*pi)` (about 2.5); X/Y patches that
  previously evaluated to zero density now contribute. Normal and tangential spreads use
  `path` and `peth`.
- **Deterministic threading with Intel compilers.** A data race in `ifx` builds changed
  threaded results by up to about 1%. Results are now bit-identical across thread counts.

## Validation

- 17 Fortran test programs pass with GNU + OpenMP, including the analytic Maxwellian
  OML check (relative error below 0.5% with default octree settings), emission
  normalisation over all six patch directions, npy I/O, batch resume and an 8-thread
  bit-identity test.
- 55 Python tests pass against the rebuilt shared library.
- Four-rank MPI batch results are bit-identical to the serial executable for both
  dust-current and velocity-range modes.
- Existing C entry points and public Python arguments are unchanged.
