# v1.6.0

## Highlights

- Adds Fortran-backed EMSES velocity-range autorange with per-cell diagnostics,
  progress logging, sparse accumulation, persistence, and validation-oriented
  accessors.
- Adds Fortran-backed adaptive octree probability evaluation for sparse velocity
  space sampling without materializing dense 6D arrays.
- Adds compact octree result helpers for per-spatial velocity/probability access,
  leaf box inspection, and compact sample slicing.
- Improves EMSES probability edge cases, including invalid records,
  no-collision results, and per-surface emission current handling.
- Expands bilingual documentation for autorange and octree workflows, including
  KUDPC `tssrun` examples and status handling.

## Validation

- `fpm test --compiler ifort`
- Python unit tests
- Python wrapper import smoke test
- `make install INSTALL_PROFILE=generic` with `FC=ifort`
